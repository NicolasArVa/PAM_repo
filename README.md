# Quantitative Analysis of Regulatory Circuits in Bacterial Systems
**Data Processing Scripts for Publication Figures**  
*Complementary to: Biosensor characterization: formal methods from the perspective of proteome fractions (2025)*  

## 📁 Repository Overview
This repository contains R scripts for processing experimental data and generating publication figures for three biosensor systems:
1. **T7 Production System** (IPTG biosensor)
2. **CymR Production System** (Cumate biosensor)
3. **MerR Production System** (Mercury biosensor)

⚠️ **Important Note**: This repository contains **only data processing scripts**, not raw data tables. Experimental data must be downloaded separately from FigShare.

## 🔗 Data Availability
All experimental datasets are available on FigShare:  
**https://doi.org/10.6084/m9.figshare.26314723.v1**  

### Instructions
After downloading datasets from FigShare:
1. run **load_all.R**
2. install packages from **packages.R**
